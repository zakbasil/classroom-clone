

## Google Classroom Replica - Demo Prototype

### Overview
A modern, polished demo of Google Classroom featuring both teacher and student experiences with role switching, built with a soft, contemporary UI design.

---

### Phase 1: Foundation & Landing

**Welcome Page**
- Engaging hero section introducing the platform
- Brief feature highlights (Classes, Assignments, Grading)
- "Explore as Teacher" and "Explore as Student" buttons
- Modern soft UI with gentle gradients and rounded elements

**Navigation & Layout**
- Collapsible sidebar with class list, calendar, and settings
- Top header with role toggle switch (Teacher ↔ Student)
- Responsive design for mobile and desktop

---

### Phase 2: Classes & Dashboard

**Class Cards Dashboard**
- Grid of class cards with cover images, class names, and teacher info
- Each card shows upcoming assignment count
- "Join Class" button (student view) / "Create Class" button (teacher view)

**Individual Class Page**
- Stream tab: Announcements, comments, and updates
- Classwork tab: Assignments organized by topic
- People tab: View enrolled students and teachers
- Materials tab: Shared resources and files

---

### Phase 3: Announcements & Stream

**Class Stream**
- Post announcements with text and mock attachments
- Comment section on each post
- Scheduled posts indicator
- Real-time-style updates within the demo

---

### Phase 4: Assignments System

**Teacher View**
- Create assignments with title, description, points, and due date
- Attach mock files/links
- View submissions list with status indicators
- Quick grade input with feedback comments

**Student View**
- View assignment details and due dates
- "Submit" button to mark work as done
- See grade and teacher feedback
- Late submission indicators

---

### Phase 5: Grading & Feedback

**Teacher Grading Interface**
- Side-by-side view: submission on left, grading panel on right
- Point input with rubric suggestions
- Private comments to students
- Return/publish grades in bulk

**Student Grade View**
- Grades summary per class
- Individual assignment feedback
- Overall class performance indicators

---

### Phase 6: Materials & Resources

**Materials Section**
- Organize resources by topic/folder
- Mock file previews (PDFs, docs, links)
- Teachers can add/edit materials
- Students can view and "download"

---

### Design Elements

**Modern Soft UI Style**
- Soft shadows and subtle gradients
- Rounded corners (12-16px radius)
- Muted, calming color palette
- Smooth hover transitions and micro-interactions
- Clean typography with good hierarchy

---

### Demo Data
Pre-populated with sample classes, assignments, and student submissions so users can immediately explore the full experience without setup.
